## 🌟 为什么做这个系统？

买彩票本质是一个极低概率事件，绝大多数人选号时容易陷入“生日号扎堆（$\le 31$）”、“图形连号对称”、“跟风选热号”的心理陷阱，导致即使极其幸运中得头奖，也往往面临成百上千人**平分奖池**的窘境。

本项目旨在解决两个核心痛点：
1. **科学层面（最大化独享期望）**：用集成机器学习预测合理概率基底，并通过**博弈论反大众算法**剔除所有历史原号与高碰撞号，追求“一旦命中，独享大奖”；
2. **实操层面（随时随地现场用）**：告别笨重电脑，通过 GitHub Actions **每周一、三、五定时在云端跑完算力并更新 Top 20 冻结候选池**；用户在彩票店现场只需掏出手机，结合**当下时空气机与心动灵感**一键起卦，毫秒级锁定最终 5 注号码！

## 🔬 核心技术三大引擎

```
                                  [ 3,530+ 期真实开奖历史库 ]
                                                │
                 ┌──────────────────────────────┴──────────────────────────────┐
                 ▼                                                             ▼
     【 引擎 1：机器学习概率集成 】                                 【 引擎 2：博弈论反大众防分奖 】
   • 随机森林 (RandomForest)                                    • 全量历史 3,530 期开奖原号 100% 硬剔除
   • L2 正则化逻辑回归 (LogisticRegression)                    • 6 连 / 5 项等差数列、4 连号、4 同尾号剔除
   • 多周期统计动量与遗漏值分析                                  • 破除生日偏置 (>31 加分，全 <=31 惩罚)
   • 对数似然比 (LLR) 平滑评分                                  • 视觉图形对称与镜像对规避
                 │                                                             │
                 └──────────────────────────────┬──────────────────────────────┘
                                                ▼
                                    【 Top 20 冻结候选池 】
                               (docs/data/pool.json 静态云发布)
                                                │
                                                ▼
                                 【 引擎 3：梅花易数河图五行终审 】
                                  (纯前端 JavaScript 毫秒级运算)
                   • 先天八卦 3-bit 爻象编码推演（主卦、互卦、变卦）
                   • 购彩时辰（地支 1~12）+ 现场心动数字起卦
                   • 河图五行归类：水(1,6)、火(2,7)、木(3,8)、金(4,9)、土(5,0)
                   • 铁律约束：严禁改动原注任何号码，单红球全局频次 <= 2
                                                │
                                                ▼
                                     【 最终现场精选 5 注 】
```

### 1. 机器学习概率集成模型
- **多模型融合**：结合多周期移动统计概率、随机森林分类器与逻辑回归分类器；
- **对数似然比（LLR）平滑映射**：对各球的预测概率与均匀基准计算相对对数优势，彻底消除传统概率乘积导致的数值极小化崩溃问题。

### 2. 博弈论“反大众 / 防分奖（Anti-Popularity）”系统
- **硬过滤（`AntiPopularityFilter`）**：
  - 100% 杜绝与历史上任意一期（3,530+ 期）完全相同；
  - 坚决剔除 6 球或 5 球等差数列（如 05 10 15 20 25 30）、4 连号、纯月份区扎堆（全 $\le 12$）、4 同尾号；
- **独享度软评分（`UniquenessScorer`）**：
  - **破除生日偏置**：重点选入 32、33 号码，对全落在大众生日区（$\le 31$）的组合施加严厉扣分；
  - **视觉图形惩罚**：扣减投注单上的镜像对称号、均匀步长分布号与文化吉利尾数扎堆号（6/8/9）。

### 3. 梅花易数河图五行终审引擎
- **严守铁律**：Top 20 候选池在云端生成后即彻底冻结，前端终审**绝对不替换、不篡改任何一颗红球或蓝球**；
- **卦象总断与契合度重排**：精准识别体用生克与变用回头克，将号码转换为河图数理五行，挑选出最顺应当刻气机的 5 注号码，并自动约束跨注红球出现频率。

## 🤖 GitHub Actions 云端无人值守流水线

你不需要为了跑模型让家里的电脑一直开机。本项目完全由 GitHub Actions 托管：

- **自动化时刻表**：每周一、三、五 **08:05（北京时间）** 定时触发；
- **全自动流水线**：
  1. 增量爬取 500彩票网最新官方真实开奖数据；
  2. 自动核对历史预测注单，回填中奖等级、奖金与累计 ROI；
  3. 重新训练机器学习模型，运行博弈论过滤，导出最新的 Top 20 候选池；
  4. 自动提交并推送至 `docs/data/pool.json`，GitHub Pages 网页同步完成热更新。

## 💻 进阶开发者与本地命令指南

如果你想在本地开发、回测或定制模型，可以在本地 Python 环境下运行：

### 1. 环境准备
```bash
git clone https://github.com/shady711xx/ssq-predict.git
cd ssq-predict
pip install -r requirements.txt
```

### 2. 常用 CLI 任务
```bash
# 1. 增量更新最新开奖数据（若需全量重爬历史，加 --rebuild 参数）
python main.py update

# 2. 重新训练模型并导出 Top 20 候选池（生成 docs/data/pool.json 与 reports/latest_pool.json）
python main.py export-pool

# 3. 本地命令行终端体验梅花易数现场选号
python main.py meihua --mode balanced --numbers 3 8

# 4. 自动核对往期中奖注单并输出对账报表
python main.py check

# 5. 运行长周期滚动消融回测 (100 期 Walk-Forward 回测)
python main.py backtest --draws 100 --seed 42

# 6. 执行全工程 81 项严格自动化测试套件
pytest -v
```
